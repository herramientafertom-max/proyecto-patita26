# ADR 0001 — Stack principal

- **Estado:** aceptado
- **Decisión:** TypeScript, NestJS, React/Vite, PostgreSQL/Supabase y Docker.
- **Alternativas:** FastAPI + React; ASP.NET Core + React.
- **Consecuencias:** un lenguaje principal, API modular y build portable; NestJS añade estructura y dependencias que deben mantenerse actualizadas.
